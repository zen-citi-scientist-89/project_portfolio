- ✓ Time-series analysis of order and payment trends

- ✓ Performance metrics and KPI calculation

**Key Skills Demonstrated:** SQL proficiency, data modeling, analytical thinking, insight generation

## 🎓 Business Questions This Project Addresses

- 🏆 **Which product categories drive the most revenue?** (segment performance)
- 💰 **How do order values vary by region and customer segment?** (geographic & cohort analysis)
- 💳 **What payment methods dominate the marketplace?** (payment behavior)
- 🔄 **Are repeat customers associated with faster delivery or higher satisfaction?** (customer retention)
- ⭐ **Which sellers have the strongest performance across products and reviews?** (seller quality)
- 📦 **Do delivery delays correlate with lower review scores?** (operations → satisfaction)
- 🌍 **What regional patterns emerge in demand and purchasing power?** (geospatial insights)

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Jupyter Notebook
- Pandas, DuckDB

### Setup

```bash
# Clone the repository
git clone https://github.com/zen-citi-scientist-89/project_portfolio.git
cd project_portfolio

# Install dependencies (recommended: use virtual environment)
pip install -r requirements.txt  # if available, or:
pip install pandas jupyter duckdb

# Start Jupyter and explore
jupyter notebook
```

### Workflow

1. **Start with `data_profiling.ipynb`** — understand the dataset structure and quality
2. **Move to `explore_schema_data_w_duck_db.ipynb`** — run analytical queries and find patterns
3. **Extend the analysis** — add custom queries, build visualizations, tell the data story
